# Публичный сайт: редизайн и игра «Соберите систему» — дизайн

## Зачем
Компания делает то же, что NAG (shop.nag.uz): продаёт оптом и в розницу оборудование безопасности и связи
(видеонаблюдение, контроль доступа, сигнализация, сетевое оборудование, PoE, Wi‑Fi, ИБП) и собирает системы «под ключ».
Два типа посетителей:
1. **Монтажники и ИТ-специалисты** — знают, что нужно; хотят быстро найти товар, цену, наличие.
2. **Владельцы магазина / офиса / дома** — не знают, что нужно; им нужна помощь с подбором.

Сейчас сайт выглядит как шаблон (тёмный «звёздный» фон, золото, подписи капсом, бегущие строки) и ничего не делает для второго типа посетителей.

## Цели
- Свой, узнаваемый вид: светлый «инженерный» каталог, читаемый, быстрый для поиска товара.
- Игра «Соберите систему» на главной: посетитель перетаскивает фигурки оборудования на картинку объекта,
  получает подсказки и список, отправляет его «на расчёт» (готовая заявка в форме контактов).
  **Что почувствовать:** «собрать систему несложно, тут помогут». **Что сделать:** отправить заявку.
- Все стили — в `Front/src/styles/`, в `.vue` стилей нет (уже так, тест охраняет).

## Не цели
- Не меняем бэкенд, API, тексты товаров, логику корзины/избранного/сравнения.
- Не меняем админку (её вид должен остаться ровно таким, как сейчас).
- Не делаем 3D и физику — простое перетаскивание.

## Анти-цели (провал, даже если «работает»)
- Игра мешает купить: закрывает каталог, тормозит, не работает пальцем на телефоне.
- Сломаны поиск, фильтры, корзина, оформление заявки.
- Новые обещания компании, которых нет в текстах сейчас (рассрочка, сроки и т. п.).

## Ограничения
- Vue 3 + Vite, без новых тяжёлых библиотек. Шрифт ставится из npm и раздаётся с нашего сервера (без Google Fonts).
- Контраст ≥ 4.5:1, кнопки ≥ 40 px, видимый фокус, `prefers-reduced-motion`, 375 px без горизонтальной прокрутки.
- Картинки игры генерирует ChatGPT в Chrome владельца; без логотипов брендов; если генерация не удалась — рисуем SVG сами.

## Подходы
1. **Переписать все стили публичной части с нуля** (новые классы, новые файлы). Чисто, но 10 тыс. строк CSS и 15 страниц —
   очень долго, высокий риск сломать мелкие состояния (фильтры, пустые корзины, мобильные меню).
2. **Разложить существующие стили по файлам, затем сменить дизайн-токены и переписать «лицо»**
   (шапка, подвал, кнопки, карточка товара, главная), а остальные страницы довести правками. ← **выбран**
   Быстрее, функциональность не трогается, всё равно получаем новый вид, а мёртвый CSS удаляется по пути.
3. Только токены (цвета/шрифт). Дёшево, но сайт останется шаблоном.

## Решения (мои, владелец передал выбор)
- **Палитра:** бумага `#F3F5F2` (холодный светлый), поверхность `#FFFFFF`, линия `#D7DDD8`, чернила `#111A15`,
  лес `#1B4332` (бренд, главные кнопки, ссылки), сигнал `#F2B705` (фон «акция/новинка», текст на нём — чернила),
  ошибка `#B42318`. Без градиентов, без «звёзд», без золота.
- **Шрифт:** Onest (variable, кириллица) через `@fontsource-variable/onest`. Шкала 14/16/18/24/32/48 px, веса 400/500/700,
  цены `tabular-nums`. Обычный регистр, без капс-подписей над заголовками.
- **Раскладка:** ширина до 1240 px, выравнивание по левому краю. Белая шапка: логотип, большая кнопка «Каталог», поиск,
  телефон, иконки избранного/сравнения/корзины. Карточки — рамка 1 px, без теней, радиус 10 px; кнопки 8 px.
- **Главная:** первый экран — заголовок + игра справа (на телефоне — под заголовком). Дальше: категории из базы,
  товары, услуги (только то, что уже написано на сайте), бренды, заявка. Бегущие строки убрать.
- **Одна анимация:** только в игре (фигурка «встаёт» на место). Остальное без «въезжающих» блоков.

## Игра «Соберите систему»
- Сцена: изометрическая картинка небольшого объекта (вход, торговый зал, касса/офис, серверный уголок, парковка).
- 8 фигурок: купольная камера, цилиндрическая камера, видеорегистратор, PoE-коммутатор, роутер, Wi‑Fi точка,
  считыватель доступа, ИБП. На сцене ~10 мест, у каждого — какие фигурки подходят.
- Перетаскивание мышью и пальцем; подходящие места подсвечиваются; неподходящее место — фигурка возвращается.
  Без мыши: нажать на фигурку → она встаёт в первое свободное подходящее место. Поставленную можно убрать (×).
- Панель «Ваша система»: список с количеством, подсказки:
  камеры без регистратора; камеры без PoE-коммутатора; есть оборудование, но нет ИБП.
- Кнопка «Отправить на расчёт» → `/contact?message=…` — форма контактов уже заполнена списком.
  Ссылки «Смотреть в каталоге» ведут в поиск каталога по названию типа.

## Что остаётся исполнителю
Точные координаты мест на сцене (после получения картинки), мелкие состояния страниц, тексты подсказок в пределах смысла выше.
