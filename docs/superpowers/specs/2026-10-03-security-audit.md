# Аудит безопасности бэкенда NCF0110 — пункты 1–4 (критические)

Дата: 2026-10-03. Объект: `back/` (Django 5.2.5, DRF 3.15.2, SimpleJWT 5.5.1), фронт `Front/` (Vue 3).

## 1. Подделка админского JWT
- `config/settings.py:25` — дефолтный `SECRET_KEY` захардкожен и лежит в репозитории.
- `config/settings.py:30` — `DEBUG` по умолчанию `True`; проверка небезопасного ключа (стр. 42) работает только при `DEBUG=False`.
- Итог: без env-переменных на проде любой, у кого есть код, подписывает JWT `{"user_id": 1}` (HS256, ключ = SECRET_KEY) и получает `/api/admin/*`.
- `ALLOWED_HOSTS` содержит `'*'`.
- Медиа раздаются только при `DEBUG` (`config/urls.py`) — прод, вероятно, работает с `DEBUG=True`.
- Требование: прод не стартует без собственного `SECRET_KEY`; утёкший ключ никогда не принимается; `DEBUG` по умолчанию выключен; хосты — явный список; картинки продолжают отдаваться.

## 2. Брутфорс пароля администратора
- Django-админка `/dashboard-ctrl-panel/` без ограничения попыток.
- `LoginRateThrottle` (5/час) обходится: DRF при `NUM_PROXIES=None` использует весь заголовок `X-Forwarded-For`, который задаёт клиент.
- Кэш LocMem — у каждого воркера gunicorn свой счётчик, сброс при рестарте.
- Требование: лимит считается по реальному IP клиента и общий для всех воркеров; Django-админка на проде выключена по умолчанию.

## 3. Подмена цены в заказе
- `OrderItemSerializer` принимает `price`, `product_name`, `product_sku` от клиента; нет лимитов на число позиций и `quantity`.
- `OrderViewSet.get_serializer_class` даёт админский сериализатор любому авторизованному (не только staff).
- Требование: цена/название/артикул берутся из `Product` на сервере; позиция без существующего товара — 400; 1–50 позиций; quantity 1–999; статус задаёт только staff. Формат запроса фронта (`CartPage.vue`) остаётся рабочим.

## 4. CSV/Formula injection в экспорте заказов
- `export_orders_csv` пишет пользовательские строки как есть; `=HYPERLINK(...)`, `=cmd|...` выполнятся в Excel у админа.
- Требование: ячейки, начинающиеся с `= + - @ \t \r`, экранируются префиксом `'`; телефоны вида `+998 90 123-45-67` остаются читаемыми.
