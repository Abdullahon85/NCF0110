# Стили админки и единая папка стилей: план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** (1) все стили проекта лежат в `Front/src/styles/`, ни в одном `.vue` нет CSS; (2) админка выглядит как спокойный рабочий инструмент магазина, а публичный сайт не меняется ни на пиксель.

**Architecture:** Блоки `<style scoped>` из 14 `.vue` переезжают в `src/styles/views/*.css` и `src/styles/components/*.css` и подключаются через `<style scoped src="@/styles/...">` — CSS физически в папке стилей, поведение `scoped` то же. Все админские разделы `main.css` (сейчас продублированы 2–3 раза: «ADMIN LAYOUT» в строках 5075, 5989, 7121) выносятся в `src/styles/admin/`, приводятся к одному правилу на элемент и ограничиваются корнями `.admin-layout` и `.admin-login-page`, после чего на них делается редизайн.

**Tech Stack:** Vue 3 + Vite, CSS без препроцессора, `node --test`. **Spec:** запрос владельца в чате 2026-11-25 («улучши стили в админке только; все стили в одной папке стилей») + навык frontend-design.

## Global Constraints
- Публичный сайт не меняется: вычисленные стили (`getComputedStyle` всех элементов) главной, каталога, страницы каталога, товара, брендов и корзины до и после совпадают, плюс сравнение скриншотов. (Это не «ни на пиксель», но очень близко.)
- Измеримые критерии админки: контраст текста ≥ 4.5:1 (вспомогательного ≥ 3:1); на 375 px `document.documentElement.scrollWidth <= innerWidth`; кликабельные элементы ≥ 40 px по высоте; у пунктов меню, кнопок и полей видимый `:focus-visible`.
- Никаких новых зависимостей и внешних шрифтов (админка работает и без интернета к Google Fonts).
- Только светлая тема (`useTheme` в проекте не используется).
- `npm run build`, `npm test`, бэкенд-тесты зелёные.

## Дизайн-направление (frontend-design, проверено против шаблонных решений)
- **Предмет:** админка магазина систем видеонаблюдения NCF в Ташкенте; 1–2 менеджера, русский язык; главная работа — быстро разобрать новые заказы и сообщения, затем вести каталог.
- **Цвета (5):** бумага `#F4F6F4` (холодный светло-серый, не кремовый), поверхность `#FFFFFF`, линия `#DCE2DD`, чернила `#17211C`, лес `#1B4332` (бренд сайта: активный пункт меню и главные кнопки). Сигнальный янтарь `#B26B00` — только для «новое/ждёт ответа», опасность `#B42318` — только для удаления. Никаких градиентов и цветных полос-«акцентов» на карточках.
- **Шрифт:** системный (`Segoe UI` на Windows, `system-ui`) — родной для рабочего инструмента, полная кириллица; характер даёт шкала 13/14/16/20/28 px, вес 600 для заголовков, `font-variant-numeric: tabular-nums` для чисел и цен. Заголовки и подписи — обычный регистр (без КАПСА в шапках таблиц).
- **Раскладка:** светлый сайдбар 240 px с текстовыми пунктами, сгруппированными по работе: «Работа» (Заказы, Сообщения, Отзывы, Вопросы), «Каталог» (Товары, Каталоги, Бренды, Теги, Характеристики), «Сайт» (Баннеры, Новости, Настройки). Иконки — линейные SVG 20 px вместо эмодзи. Заголовок страницы один (сейчас он повторяется в шапке и в контенте). Таблицы плотные, строка 44 px, числа и цены выровнены вправо. Выравнивание — по левому краю.
- **Одна смелая вещь:** на дашборде вместо шести одинаковых карточек — полоса «Требует внимания» (новые заказы, непрочитанные сообщения, отзывы и вопросы на модерации) с прямыми ссылками; остальная статистика — тихая строка цифр.
- Обязательно: видимый фокус с клавиатуры, `prefers-reduced-motion`, работа на 375 px.

## Review Focus
1. Длинные названия товаров/каталогов в таблицах — перенос внутри ячейки, таблица не вылезает за экран.
2. Ширина 375 px — сайдбар выезжает поверх контента, таблицы прокручиваются горизонтально внутри своей рамки.
3. Навигация с клавиатуры (Tab) — видимый фокус на пунктах меню, кнопках, полях.
4. Пустые списки — понятное «пустое состояние» с действием («Добавить товар»), а не серая строка.
5. Модальные окна на маленьком экране — кнопки «Сохранить/Отмена» всегда видны.
